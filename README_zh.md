## 💫 关于我 

- 🎓 **教育背景**: 2024年入学于 **大连理工大学 (DUT)**，主修 **人工智能** 专业。
- 🔬 **研究方向**: 对 **大语言模型 (LLM)**、**多模态大语言模型 (MLLM)** 以及 **AIGC** 充满热情。
- ⚙️ **核心技术**: 探索生成式模型 (**Diffusion Models**, **Flow Matching**) 与大模型后训练技术 (**RLHF**, 使用veRL框架的 **GRPO**)。
- 💡 **目标**: 通过代码与研究来学习和分享知识，致力于为前沿AI技术做出贡献。
